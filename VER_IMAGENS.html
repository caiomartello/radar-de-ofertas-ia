Radar de Ofertas IA

Galeria estática de capturas reais. Estas imagens não são o aplicativo interativo. O dashboard mostra dados fictícios dos testes. Esta página funciona sem internet e não coleta dados.

Como testar o aplicativo no Windows

  1. Extraia todo o ZIP usando “Extrair tudo”.
  2. Para ver estas imagens, abra VER_IMAGENS.html com dois cliques. Isso não precisa de Node.js.
  3. Para testar o aplicativo real, instale o Node.js 24 LTS pelo site oficial nodejs.org, se ainda não estiver instalado.
  4. Na pasta extraída, abra INICIAR_RADAR.cmd com dois cliques. Na primeira abertura, as dependências serão baixadas gratuitamente. Aguarde a mensagem do programa.
  5. Crie sua conta quando o terminal pedir nome, e-mail e senha pessoal. A senha não aparece durante a digitação. Não compartilhe sua senha no chat.
  6. O navegador abrirá automaticamente quando o servidor estiver pronto. Entre com a conta criada e clique em Experimentar com exemplos.
  7. Mantenha a janela do terminal aberta durante o teste. Para encerrar, use Ctrl+C nessa janela.

Esta execução usa somente seu computador. Não publica o aplicativo, não usa o banco da nuvem e não contrata serviços pagos. O iniciador foi preparado neste ambiente Linux; não foi executado em um Windows real.
